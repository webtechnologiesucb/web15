1 · Signals: set, update y lectura

Los signals son valores reactivos: se leen con () y avisan a la plantilla cuando cambian. Con signal() creamos estado escribible; la plantilla no muta nada, sólo llama a métodos del componente.

Valor: {{ contador() }}

Doble: {{ doble() }}

Tipo: {{ parOImpar() }}

El botón reiniciar devuelve el contador a 0 y vacía el registro de movimientos.

2 · Valores derivados con computed()

Con computed() calculamos valores a partir de otros signals. Sólo se recalcula cuando cambian sus dependencias, y nunca se escribe en él: el estado derivado no se duplica.

3 · Inmutabilidad: arrays y objetos

Los signals no detectan mutaciones internas: comparan referencias. Debemos crear un array u objeto nuevo para que Angular se entere del cambio.

4 · linkedSignal y model()

linkedSignal enlaza un signal a otro pero puede modificarse independientemente. model() crea un input de doble sentido: el hijo puede escribir en él y el padre recibe el cambio con [(value)].

El padre lee la valoración actual: {{ rating() }} / 5.
