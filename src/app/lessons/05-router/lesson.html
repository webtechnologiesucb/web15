1 · RouterLink y RouterLinkActive

Los enlaces del router son declarativos y no recargan la página. RouterLinkActive añade una clase cuando la URL activa coincide con el enlace.

@for (resource of resources; track resource) { {{ meta[resource].icon }} {{ meta[resource].plural }} }

Estás en

{{ currentUrl() }}

Los chips de arriba navegan al explorador real. Al volver, la lección sigue en el mismo sitio.

2 · Parámetros de ruta como inputs

Con withComponentInputBinding(), los parámetros :resource y :id llegan al componente como input(). Ya no hace falta inyectar ActivatedRoute para leerlos.

@for (resource of resources; track resource) { }

Query param demo: {{ demoResource() }} · {{ demoMeta().plural }}

La URL cambia sin recargar el componente; el estado activo se deriva de la URL.

3 · Carga diferida y títulos

Cada lección y cada vista se carga con loadComponent: sólo se descarga el chunk cuando la ruta se visita. El title de la ruta actualiza el título de la pestaña.

@for (row of routeRows; track row.path) {
/{{ row.path }} {{ row.component }} {{ row.title }}
}

La ruta '**' va al final: cualquier URL que no encaje antes cae en la página 404.
